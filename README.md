# 🛕 Temple Recommendation System

## 📖 About
A **Streamlit-based web app** that recommends ancient Indian temples based on description similarity using **TF-IDF + Cosine Similarity**.  
It also shows temple locations on an interactive **Folium map** and highlights top heritage places in India.

---

## 🚀 Features
- 🔍 Content-based temple recommendations from user descriptions  
- 🗺️ Interactive map with temple locations  
- ⭐ View top famous temples and monuments in India  
- 🎨 Gradient UI with clean layout  

---

## 🛠️ Technology
- **Python**  
- **Streamlit** (web app)  
- **Pandas, NumPy** (data handling)  
- **Scikit-learn** (TF-IDF, cosine similarity)  
- **Folium + streamlit-folium** (interactive maps)
